## 三、项目最终成果
核心交付物为**鸟类声音识别APP**，核心功能要求：
1. 完成前端页面开发，包含交互按钮，实现鸟声录制功能
2. 实现前端交互，将录制的鸟声传输至服务器端
3. 服务器端完成识别后，将结果返回前端并展示

## 四、技术路径与模型复现
1. 核心技术路径：音频文件转频谱图，基于CNN等模型完成声音识别
2. 模型筛选方案：并行训练GitHub上的不同开源模型，通过准确率等指标对比，筛选最优方案
